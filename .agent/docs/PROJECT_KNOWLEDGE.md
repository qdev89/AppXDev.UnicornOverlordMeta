## 🎯 Project Overview
**Unicorn Overlord Meta Engine & Master Tactics Hub** is an interactive 5v5 tactical simulator, class compendium, relic catalog, and coliseum squad builder for the tactical RPG *Unicorn Overlord*.

It provides high-precision tactical simulation, Start-of-Battle passive conflict resolution, AP/PP action expenditure, unit synergy analysis, and team composition management.

## 🏗️ Architecture Summary
- **Framework:** Next.js 15.5 (App Router, Client Components, Static Export Parity)
- **Styling:** Vanilla CSS & Tailwind CSS with a custom Medieval Dark-Gold Glassmorphism design system.
- **Icons & Animation:** `lucide-react`, `framer-motion`, `canvas-confetti`.
- **State & Storage:** Local state, `localStorage` (`unicorn_squad_builder_wip`, `unicorn_saved_builds`), Base64 URL share codes with hash routing (`#builder?code=...`).

## 🧠 Key Decisions
1. **Initiative-Based Start-of-Battle Suppression:** Enforced strict game rule where only the unit with the highest Initiative across both teams executes their Start-of-Battle passive skill.
2. **Local Image Asset Mirroring:** Concurrently fetched and stored all 735 wiki assets locally in `public/images/` to prevent external CORS/404 image failures.
3. **Base64 URL Hash State Sharing:** Encoded 5-unit formation slots into base64 URL hashes (`#builder?code=...`) to enable shareable build links without requiring a database backend.
