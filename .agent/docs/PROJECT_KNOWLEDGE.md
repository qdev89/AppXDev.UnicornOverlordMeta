## 🐛 Solved Issues & Gotchas
1. **Hero Unit In-Game Tactics Filter Mismatch:**
   - *Problem:* Inspecting units matched squad-level summary steps. If a squad had only 1 summary step for that hero, only 1 tactic row appeared in the modal.
   - *Fix:* Built `generateComprehensiveTactics(...)` in `BuildDetailModal.tsx` combining class active/passive skills, equipped item granted skills, and authentic condition logic (e.g. `[Target: Full Row (2+ Enemies)]`, `[Self AP >= 2]`).
2. **Active vs Passive Skill Identification in Modal:**
   - *Problem:* Text substring checks accidentally classified `Holy Light` as passive due to the word "light".
   - *Fix:* Refactored `isPassive` to check for `PP` costs or `Start of Battle` triggers, while active skills are identified strictly by `AP` costs.
3. **Hydration Warning on Chrome Extension Attributes:**
   - *Problem:* Chrome extensions injecting attributes (`data-new-gr-c-s-check-loaded`) on `<body>` caused React hydration mismatch warnings.
   - *Fix:* Added `suppressHydrationWarning` on `<html>` and `<body>` in `src/app/layout.tsx`.
4. **Duplicate React Keys in Map Loops:**
   - *Problem:* Multiple units of same class IDs caused key collisions when rendering `key={u.unitId}`.
   - *Fix:* Changed keys to `key={`${u.unitId}-${uIdx}`}` across all list views.
