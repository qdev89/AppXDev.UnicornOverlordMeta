## 🐛 Solved Issues & Gotchas
1. **Hero Unit In-Game Tactics Scope Leak:**
   - *Problem:* Inspecting units without explicit steps in high-level squad sequences caused `displayedTactics` to fall back to the aggregate squad sequence (Selvie/Auch's Trinity Nuke), making tactics fail to reload on unit click.
   - *Fix:* Built `generateUnitTactics(...)` in `BuildDetailModal.tsx` to dynamically construct authentic hero-specific active/passive tactics rules.
2. **Grammarly / Browser Extension Hydration Mismatch:**
   - *Problem:* Chrome extensions injecting `data-new-gr-c-s-check-loaded` onto `<body>` before React hydration threw console errors.
   - *Fix:* Added `suppressHydrationWarning` on `<html>` and `<body>` in `src/app/layout.tsx`.
3. **Duplicate React Keys in Map Loops:**
   - *Problem:* Duplicate hero classes (e.g. 2x `great-knight` or 2x `swordmaster`) caused key collisions when rendering `key={u.unitId}`.
   - *Fix:* Changed keys to `key={`${u.unitId}-${uIdx}`}` in `ZeroOverlapTop10.tsx`.
